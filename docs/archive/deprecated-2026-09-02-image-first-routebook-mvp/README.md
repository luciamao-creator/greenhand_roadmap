# 已废弃方案归档：图像优先离线路书包 MVP

## 文档状态

- 状态：已废弃，不再继续演进
- 废弃日期：2026-09-02
- 上位约束：`SOUL.md`

## 废弃原因

- 旧方案以 `离线路书包 + 处理过的地图图像` 为 MVP 核心表达。
- 继续讨论后确认，该方案在首批线路规模下存在以下核心问题：
  - 路线图像生产成本高；
  - 每条线路所需标注数据难以稳定拿全、拿准；
  - 图像质量与事实准确性难以建立低成本评测体系；
  - 对个人开发者而言，内容生产链和维护成本不可持续。

## 替代方案

- 当前方案不再以自定义地图图像渲染为 MVP 核心。
- 当前方案改为：
  - `精选新手路线库` 作为内容边界；
  - `现成地图底座 + 路线跟随/导航能力` 作为在途能力；
  - `AI/RAG` 用于资料整理、标签生成、摘要生成、FAQ 问答、推荐解释和 checklist 组合；
  - 只收录 `成熟公开、可查可证、适合新手` 的线路。
