# 线路录入模板 V1

## 1. 文档信息
- 状态：V1 待执行
- 日期：2026-09-02
- 适用范围：业务侧整理候选线路、内容侧录入后台、产品侧审核
- 关联标准：`docs/requirements/route-content-materials-spec-v1.md`
- 关联筛选：`docs/requirements/route-selection-criteria-v1.md`

## 2. 使用说明
- 一条线路填写一份；
- 尽量结构化填写，不写成长篇游记；
- 空缺字段用 `待补充` 标注，不要留空不说；
- 对新手安全判断有影响的信息优先填写。

## 9. 最低录入完成标准
- 主记录完整度达到 80% 以上；
- 至少 3 个关键节点；
- 至少 1 个重点岔路；
- 至少 1 个下撤点；
- 至少 1 个禁区或明确说明“无已知禁区但不得离开成熟步道”；
- 至少 3 张可用图片；
- 六维评分已填写。

## 10. 推荐交付方式
- 业务侧可先用本模板在飞书文档、表格或 Markdown 中填报；
- 内容侧再将结构化内容迁移到正式后台；
- 样板线建议先由 1 位业务 + 1 位产品共同完成一次，校准标准后再批量推进。
