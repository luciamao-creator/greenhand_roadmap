## 2. 线路主记录示例

```text
一、基础信息
线路名称：杭州九溪烟树 - 龙井村轻徒步线（演示样例）
省份：浙江
城市/区域：杭州 / 西湖风景名胜区周边
路线别名：九溪 - 龙井新手友好步道
路线类型：往返 + 短环线可选
公开成熟步道：是
建议季节：春、秋、初冬
不建议季节：连续暴雨日、夏季午后闷热雷雨时段
预计总时长：150-210 分钟
预计距离：6-8 公里
预计爬升：180-260 米
体力强度：低
适合人群：首次徒步用户、周末轻运动用户、拍照型用户、朋友结伴轻出行用户
不适合人群：追求高强度拉练用户、需要极强挑战感用户、雨天不愿走湿滑石板路用户
交通方式：打车或公共交通到九溪公交站/九溪入口，再步行进入
集合/到达建议：建议上午 8:30-10:00 入线，避开午后人流和闷热时段

二、产品定位判断
为什么适合新手：整体路线成熟，景观连续，岔路虽有但可通过参照物清晰表达，体能门槛不高，适合作为“第一次觉得自己也能完成徒步”的样板线。
最突出的景观审美标签：溪谷感
最突出的安全感标签：成熟步道
最突出的轻松成就标签：周末可完成
一句话推荐语：一条让新手在杭州也能获得“森林溪谷轻成就感”的入门路书。

三、风险与边界
最容易慌的点：从九溪主线转入上行步道时，用户容易怀疑“是不是要离开溪流继续往上走”
最容易走错的点：靠近龙井村前的岔口，用户可能会顺着游客流进入非目标方向支路
禁区或不要进入区域：不要离开成熟石板步道或木栈道进入溪边湿滑石面和林间小路；部分看似近路的小土路不作为推荐路径
高风险天气提醒：暴雨后溪边石面湿滑风险明显上升；雷雨天气不建议入线；高温天需避免正午长时间暴晒段
信号较弱区：整体城区周边信号通常可用，但局部山坳段可能出现短暂弱信号，不能因此放弃提前下载离线路书包
是否有明确下撤点：是
下撤说明：中段可沿成熟道路返回九溪入口；靠近龙井村后可通过村路和常规道路下撤
是否存在台阶多/暴晒/湿滑/涉水：有湿滑风险；局部缓坡和石阶；不建议涉水穿溪
其他不适合新手的因素：节假日人流较多，会影响安静感；雨后若鞋底抓地力差，体验会明显下降

四、路线结构
起点名称：九溪入口
终点名称：龙井村观景休息点（演示终点）
路线分段建议：
- 第 1 段：九溪入口 - 溪谷缓行段。用户先建立“沿溪步道”安全感。
- 第 2 段：溪谷上行 - 林荫过渡段。用户会第一次遇到方向判断压力。
- 第 3 段：上行转折 - 龙井村接近段。重点关注岔路和是否继续上行。
- 第 4 段：龙井村休息点 - 原路返回或常规道路下撤段。
关键节点数量：5
关键节点概览：九溪入口、沿溪石桥、上行转折口、龙井前岔路、龙井休息点
重点岔路数量：2
重点岔路概览：溪谷转上行岔路、接近龙井村前游客分流岔路
下撤点数量：2
下撤点概览：中段原路返回点、龙井村道路下撤点

五、应急与联系
景区/管理方联系方式：待正式录入时补充景区/管理处官方电话
救援/应急联系方式：待正式录入时补充当地公开应急电话
报警相关说明：紧急情况优先拨打 110 / 120，并同步联系同行人
其他本地提醒：如遇临时封闭、施工或天气管制，以现场公告为准

六、checklist 建议
基础装备：防滑运动鞋、小背包、饮水、纸巾、充电宝
饮水食物：至少 500-800ml 饮水，建议携带轻便补给
通讯与电量：手机满电出发，建议开启省电模式并提前下载离线路书包
鞋服建议：透气长裤或速干裤，避免光滑鞋底
雨天加严项：防滑更好的鞋、备用袜子、简易雨具、防水袋
降温加严项：轻薄外套、防风层

七、素材清单
封面图：待补充 2 张，建议包含溪谷和林荫视角
景观图：待补充 3-4 张，建议包含石桥、溪流、林荫步道、龙井村边缘视角
关键参照物图：待补充 5 张，对应 5 个关键节点
岔路图：待补充 2 张，对应两个重点岔路
禁区图：待补充 1 张，标示不建议进入的溪边/小土路区域
轨迹文件：待补充 GPX 或 GeoJSON
地图标注截图：待补充 1 套，总览图 + 两张局部重点图
资料来源：待补充公开步道资料、实采记录或可信地图标注来源

八、初筛结论
是否命中一票否决：否
六维评分：
- 新手友好度：5
- 安全边界清晰度：4
- 参照物表达力：5
- 景观审美表现力：5
- 内容素材完备度：3
- 可运营性：5
- 总分：27
结论：P0 优先
备注：很适合作为浙江样板线，但正式进入内容库前必须补齐轨迹、图像、应急联系和天气边界核验。
```

## 4. 岔路重点录入子模板示例

### 岔路 A

```text
岔路名称：溪谷转上行岔路
所属线路：杭州九溪烟树 - 龙井村轻徒步线（演示样例）
坐标：待实采补充
正确方向：离开纯沿溪方向，转入成熟上行步道
错误方向：继续贴近溪边走向非目标支路
为什么容易走错：新手直觉会认为“沿着水一直走更安全”
用户此处应看到什么：清晰路面、可上行步道、明显参照物转折
是否有现场照片：待补充
是否需要禁区叠加：是
一句提醒文案：看到成熟上行步道时请上行，不要继续贴溪走小路。
```

### 岔路 B

```text
岔路名称：龙井前游客分流岔路
所属线路：杭州九溪烟树 - 龙井村轻徒步线（演示样例）
坐标：待实采补充
正确方向：按路书指向龙井休息点或明确下撤方向
错误方向：盲目跟随游客人流进入非目标支路
为什么容易走错：用户会把“人多”误认为“正确”
用户此处应看到什么：村落边缘分流点、方向变化、可识别标志物
是否有现场照片：待补充
是否需要禁区叠加：否
一句提醒文案：人多不等于方向对，请以路书指定方向为准。
```

```text
正确替代路径说明：始终停留在成熟石板路/栈道/明确土路主线上
是否需要强提醒：是
```

## 7. 这个样板线为什么适合作为示例

- 它符合新手友好、成熟公开、城市周边可达的样板线特征；

- 它能明显演示“参照物表达”和“岔路强提醒”两种核心产品能力；

- 它不依赖极限参数，适合验证我们的产品语言是否真正站在新手视角；

- 它也暴露了一个关键事实：即便是看起来容易的路线，正式入库前仍必须补齐真实坐标、风险边界和图像素材。

## 8. 下一步如何使用这份样例

- 业务侧可直接照着这份样例填第一条真实线路；
