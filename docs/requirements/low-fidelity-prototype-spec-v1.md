## 2. 文档目标

- 将当前 MVP 的核心页面落成可执行的低保真页面说明；

- 明确每个页面从上到下的模块顺序、核心内容和 CTA 关系；

- 为后续视觉设计、组件拆分和页面开发提供统一蓝本；

- 保持当前确认的审美方向：`OTA App + 地图 App` 的简约清爽风格。

## 3. 原型原则

### 3.1 布局原则

- 优先单列垂直流布局；

- 首页和详情页优先卡片化；

- 导航页优先全屏地图 + 底部抽屉；

- 主按钮始终只保留一个明确主行动。

### 3.2 文字原则

- 文案优先回答用户最直接的问题；

- 参数只作为辅助，不抢占首屏；

- 风险提示要保守直接，不做热血表达；

- AI 输出文案必须像“编辑过的推荐理由”，不能像聊天记录。

### 3.3 审美原则

- 颜色基底为白、浅灰、低饱和自然色；

- 大卡片、大留白、小标签；

- 地图和卡片的边界清楚，但不厚重；

- 不采用复杂分栏、密集图标矩阵和重装户外风。

## 5. LF01 首页

### 5.1 页面目标

- 让用户在 5 秒内理解产品是干什么的；

- 让用户在 15 秒内进入选线动作；

- 避免首页变成杂乱的运营广场。

### 5.2 页面结构

```text
顶部安全区
  -> 城市/省份切换
  -> 轻量搜索入口

主标题区
  -> 主标题
  -> 副标题
  -> 今日状态提示

快捷入口区
  -> 更轻松
  -> 风景更好
  -> 更安心

本周推荐区
  -> 横向路线卡片 2-4 张

四省入口区
  -> 四川
  -> 浙江
  -> 广东
  -> 福建

安全说明轻入口
```

### 5.3 模块说明

#### 顶部安全区

- 左侧显示当前默认省份或城市；

- 右侧为轻量搜索入口；

- 不放头像、消息、会员等非 MVP 内容。

#### 主标题区

- 主标题建议：

  - `先去那些适合新手的山`

- 副标题建议：

  - `只收录成熟公开路线，帮你从不知道去哪到敢去、走稳、能回来`

- 今日状态提示：

  - 可显示类似 `今天更适合短线 / 雷雨天谨慎` 的轻提示。

#### 快捷入口区

- 三个并列胶囊卡片：

  - `更轻松`

  - `风景更好`

  - `更安心`

- 点击后跳转路线发现页，并自动带入筛选条件。

#### 本周推荐区

- 用横向滑动的中大卡片展示；

- 单卡字段：

  - 路线名；

  - 城市；

  - 一句新手理由；

  - 时长/爬升简述；

  - 1-2 个标签。

#### 四省入口区

- 采用 2x2 小卡片网格；

- 每张卡片展示：

  - 省份名；

  - 一句典型体验，如 `溪谷茶山`、`城市周边山`。

### 5.4 CTA

- 首屏主 CTA：无单独按钮，由快捷入口和推荐卡承担；

- 次 CTA：`查看全部路线`

### 5.5 状态

- 加载中：主标题骨架屏 + 推荐卡骨架屏；

- 空状态：提示“先从你附近开始选”；

- 天气高风险：在主标题区下方显示轻量风险 banner。

## 6. LF02 路线发现页

### 6.1 页面目标

- 帮用户快速缩小路线范围；

- 让用户比较路线，而不是研究地图。

### 6.2 页面结构

```text
顶部导航栏
  -> 返回
  -> 页面标题
  -> 筛选入口

筛选条
  -> 省份
  -> 标签
  -> 时长
  -> 强度

推荐排序栏
  -> 推荐优先
  -> 更轻松
  -> 更安心

路线列表
  -> 路线卡 1
  -> 路线卡 2
  -> 路线卡 3

底部辅助切换
  -> 列表视图
  -> 小地图预览
```

### 6.3 路线卡结构

```text
左：封面图缩略
右：
  -> 路线名
  -> 区域
  -> 一句适合新手理由
  -> 指标行：时长 / 距离 / 爬升
  -> 标签行：1-3 个
  -> 今日天气/时间提示
```

### 6.4 交互说明

- 默认进入列表视图；

- 小地图预览只作为辅助切换，不做全屏强地图；

- 筛选变更后，列表即时刷新；

- 点击路线卡进入详情页。

### 6.5 CTA

- 页面级 CTA：无固定底部主按钮；

- 路线卡点击为主动作。

### 6.6 状态

- 无结果：给出“放宽时长/强度条件”的建议；

- 弱网：保留上次列表缓存，并提示“结果可能不是最新”。

## 7. LF03 路线详情页

### 7.1 页面目标

- 在 1 屏半内回答“适不适合我”；

- 引导用户从看详情走向准备和出发。

### 7.2 页面结构

```text
顶部沉浸式封面区
  -> 路线封面图
  -> 返回
  -> 收藏占位（后续）

摘要卡
  -> 路线名
  -> 城市/区域
  -> 一句定位
  -> 标签

适合新手说明卡
  -> 为什么适合
  -> 最容易慌的点
  -> 什么人先别去

参数卡
  -> 时长
  -> 距离
  -> 爬升
  -> 最佳时间

天气与风险卡
  -> 今日天气摘要
  -> 不适合条件
  -> 预警入口

路线逻辑卡
  -> 起点到终点怎么走
  -> 是否往返
  -> 何时该收手

FAQ 卡
  -> 3-5 条折叠问答

底部固定 CTA 区
  -> checklist
  -> 开始导航
```

### 7.3 关键信息呈现顺序

- 先给“适不适合我”；

- 再给“累不累”和“什么时候别去”；

- 最后才是 FAQ 和更细说明。

### 7.4 CTA 设计

- 右侧主按钮：`开始导航`

- 左侧次按钮：`出发前准备`

- 当天气高风险时，主按钮改为：

  - `暂缓出发`

  - 继续导航入口降级为次动作

### 7.5 状态

- 路线暂停推荐：

  - 顶部出现醒目状态条；

  - 底部主 CTA 取消；

  - 替换为“查看原因”。

## 8. LF04 出发前准备页

### 8.1 页面目标

- 让用户在正式进入导航前完成一次保守检查；

- 明确提醒“不满足条件就别去”。

### 8.2 页面结构

```text
顶部进度区
  -> 路线名
  -> 当前步骤：出发前准备

状态总结卡
  -> 今日是否适合
  -> 当前时间是否适合
  -> 是否存在明显风险

checklist 总览卡
  -> 基础必带
  -> 天气加严项
  -> 风险加严项

重点提醒卡
  -> 今天最需要注意的 2-3 件事

确认区
  -> 我已看完 checklist
  -> 我理解今天的风险提示

底部固定 CTA
  -> 继续开始导航
```

### 8.3 交互说明

- checklist 区默认折叠摘要，点击展开全量；

- 重点提醒卡内容更短、更尖锐；

- 未完成确认前，不允许直接进入导航。

### 8.4 CTA 逻辑

- 默认禁用主按钮；

- 勾选必要确认后启用 `继续开始导航`。

### 8.5 状态

- 高风险天气：顶部状态卡变红/橙色等级；

- 系统建议取消时：

  - 主按钮改为 `暂不出发`

  - 导航入口仅保留弱入口。

## 9. LF05 在途导航页

### 9.1 页面目标

- 回答“我现在是不是还走对了”；

- 在岔路、偏航、天气变化时及时让用户收手或修正。

### 9.2 页面结构

```text
全屏地图
  -> 当前定位点
  -> 推荐路线
  -> 关键节点
  -> 岔路点
  -> 下撤点
  -> 风险点

顶部状态栏
  -> 当前路线名（缩略）
  -> 当前阶段
  -> 天气风险轻状态

右下浮动按钮组
  -> 回到我的位置
  -> 展开路线概览

底部抽屉（默认半展开）
  -> 当前状态摘要
  -> 距离下一关键点
  -> 偏航状态
  -> 下撤建议
  -> 今天天气提示

风险提示条（按需出现）
  -> 偏航提醒
  -> 接近岔路
  -> 建议收手
```

### 9.3 抽屉内容结构

```text
标题：你现在在第 X 段
副标题：继续沿主路走，别急着抄近

信息行 1：距离下一关键点
信息行 2：离路线是否偏移
信息行 3：建议下撤时间/节点

快捷入口：
  -> 看下撤说明
  -> 看天气
```

### 9.4 交互说明

- 默认半展开，拖拽可全展开；

- 全展开时展示更多节点和下撤说明摘要；

- 不在导航页展示长 FAQ；

- 所有风险提示优先采用轻量条幅和卡片，不频繁打断。

### 9.5 核心状态

- `正常`

  - 文案：`你还在推荐路线内`

- `接近关键点`

  - 文案：`前面是关键判断点，留意主路方向`

- `轻度偏航`

  - 文案：`你正在偏离推荐路线，建议停下来确认`

- `建议收手`

  - 文案：`现在继续走的风险在升高，建议就近回撤`
