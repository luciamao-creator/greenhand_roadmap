# 当前 MVP 产品策略决策：精选新手路线库

## 文档状态

- 状态：已确认，当前生效
- 日期：2026-09-02
- 适用阶段：MVP 产品定义与研发准备
- 上位约束：`SOUL.md`

## 背景

- 项目目标仍然是面向徒步新手小白，而非发烧友或野线用户。
- 经过前序方案验证与成本讨论，确认 `图像优先离线路书包` 方案不适合作为当前 MVP 主路径。
- 新的第一性原理是：先只服务那些 `新手本来就应该去、也更可能去` 的成熟公开线路，而不是试图覆盖广泛且复杂的山野场景。

## 已确认决策

### 1. 产品边界重置

- 当前 MVP 不再以 `自定义地图图像渲染` 为核心差异化。
- 当前 MVP 的核心对象改为 `精选新手路线库`。
- 路线库只收录 `成熟公开、可查可证、适合新手` 的线路。

### 2. 在途能力定义

- 当前 MVP 需要具备 `路线跟随型导航能力`，而不是只做静态离线地图查看。
- 当前 MVP 的导航能力优先定义为：
  - 当前位置显示；
  - 路线轨迹展示；
  - 偏航提醒基础能力；
  - 关键节点/岔路提醒；
  - 下撤与天气风险提醒。
- 当前 MVP 不以复杂 turn-by-turn 或动态重规划为前提。

### 3. 地图表达策略

- 当前 MVP 优先使用 `现成地图底座`，并尽量选择能够体现地形或海拔高差的表达方式。
- 是否采用 3D、卫星或海拔剖面能力，取决于后续地图底座选型。
- `Google Earth` 可作为体验参考，但当前未确认其为正式产品底座。

### 4. AI 能力边界

- `AI/RAG` 用于：
  - 路线资料整理；
  - 标签生成；
  - 摘要生成；
  - FAQ 问答；
  - 推荐解释；
  - checklist 组合生成。
- `AI` 不负责：
  - 生成核心地图真相；
  - 决定禁区边界；
  - 决定主路线事实；
  - 生成用于上线承诺的核心导航图像。

### 5. 内容范围

- 优先收录用户心智上属于 `能卖烤肠的山` 的成熟轻徒步/近郊爬山路线。
- 只做新手高频会去的路线，不做野线、灰色线路和强依赖经验判断的路线。
- 首期省份仍为：`四川、浙江、广东、福建`。
